# FriendSlop

Developed in Unity, FriendSlop is a 5-player 3D sandbox and survival pirate game. Featuring a custom physics-based combat system, grappling hook mechanics, and open-world piracy elements, the game offers players the freedom to explore, fight, and survive together on the high seas.

## Current State & Key Features
* **Engine:** Unity 3D
* **Genre:** Multiplayer, Sandbox, Survival, Action
* **Core Mechanics:**
  * 5-player co-op gameplay
  * Physics-based melee combat
  * Grappling hook / harpoon mechanics (early build)
  * Sailing dynamics and open-world exploration
